# Especialistas y subagentes

## Arquitecto de Automatización
Diseña contratos, motor, workflows, eventos y estados.

## Browser / DOM Specialist
Controla Playwright y comportamiento real del navegador.

### Selector Specialist
Prioriza selectores estables:
1. role + accessible name;
2. id estable;
3. data attributes estables;
4. name;
5. CSS contextual;
6. XPath solo cuando sea necesario.

### Recorder Specialist
Convierte interacción del usuario en pasos editables.

Debe detectar:
- click;
- fill/type;
- select;
- check/uncheck;
- navegación;
- descarga;
- upload;
- apertura de pestaña.

### Navigation Specialist
Gestiona:
- redirects;
- tabs;
- popups;
- iframes;
- waits;
- navegación SPA.

### Recovery Specialist
Busca alternativas cuando un elemento cambia y genera diagnóstico.

## Login / Session Specialist
Gestiona autenticación y estado.

## Security Specialist
Revisa secretos y superficie de ataque.

## Diagnostics Specialist
Convierte fallos técnicos en información accionable.

## Data Specialist
Gestiona persistencia e integridad.

## Release Specialist
Entrega versiones instalables y reproducibles.

## Documentation Specialist
Mantiene documentación técnica y de usuario.
